# The reference matrix — everything, as text

This file exists so that the folder can be used **without reading all fourteen other files**,
and so that nothing is only available as a picture. Five matrices, each answering one
question.

| § | Question it answers |
|---|---|
| **1** | *What animals are there, and what is the one fact about each?* |
| **2** | *I need a part with property X. Which species and which region?* |
| **3** | *What does this word mean, and which level is it?* |
| **4** | *What is the failure mode, and what do I do about it?* |
| **5** | *How does the shape of the raw material constrain my layout?* |

Confidence markers as everywhere in this folder: **✓** named source · **~** single or vendor
source, direction reliable, number not · **✗** conflicted.

## 2. Decision matrix — property wanted ⟶ species and region

The reverse lookup. "I need X" on the left.

| I need… | Best choice | Second choice | Avoid |
|---|---|---|---|
| **Least stretch in a long part** | bovine **butt**, parallel to backbone | equine **strip**; cordovan | belly, any species |
| **Highest strength per mm** | **kangaroo** (uniform parallel fibre) ✓~ | shark; fish leathers (crosswise fibre) ✓ | chicken, rabbit |
| **Most uniform over a large area** | bovine **bend/butt**; **kangaroo** for whole-skin uniformity | calf | sheep (most variable ✓), belly |
| **Fine grain for small clean goods** | **calf** | goat; **peccary** | bull neck; pig (pattern is through-thickness) |
| **Softest** | **sheep**, emu ~ | deer; ostrich body ✓ | elephant, camel, buffalo |
| **Hardest surface / scratch resistance** | **stingray** (Mohs ~5 ✓) | crocodilian hornback; shark | snake (lifts), chicken |
| **A surface that will not peel** | stingray (fused beads ✓) | crocodilian belly; bovine | **snake** (free-edged scales) |
| **A fold that will not craze** | **shell cordovan** (no grain ✓) | ostrich body (quills are soft ✓); kangaroo (creases but does not crack ✓) | any plated hide; caiman |
| **A recognisable pattern** | ostrich **full quill** | crocodilian belly tiles; pirarucu scales | — |
| **Thin + strong + light** | kangaroo 0.6–0.8 mm ✓ | salmon; chicken thigh ~ | elephant (floor ~1.2 mm ✓) |
| **Abrasion-resistant edge** | **ostrich leg** ✓; bovine shank | stingray | sheep, chicken |
| **Maximum area per hide** | bovine side; bison side | kangaroo 5–7 sq ft ✓; ostrich 11–20 sq ft ~ | toad 17–27 cm ✓; salmon ~0.8 sq ft ✓ |
| **Best value in a small skin** | goat | tilapia (~$12/hide ~); chicken | crocodilian, ostrich crown |
| **Workable with hand tools, no lining** | bovine veg-tan | goat; kangaroo | fish (needs lining ~), snake |
| **An ethical/by-product story** | **kangaroo** (not farmed, culled under management ~) | fish (fishing by-product ✓); chicken (poultry by-product ~) | elephant, hippo, seal — legality first |

## 4. Failure-mode index

| Failure | Where it happens | Mechanism | Fix |
|---|---|---|---|
| **Grain crack / crazing** | grain-corium junction, at folds | stiff film on compliant substrate | bigger radius; read `../durability.md` §2b |
| **Finish flaking / lifting** | finish-to-grain interface | **adhesion**, not mechanics | re-finish; spacing formulae do not apply (§2c) |
| **Hinge sag / stretch** | long parts cut across the fibre direction | anisotropy | re-cut parallel to backbone; one piece, butt |
| **Crease cracking in caiman** | between osteoderm-bearing scales | **brittle plates in a soft matrix** | do not use caiman structurally |
| **Scale lift / peel** | snake, lizard | **free-edged keratin folds** | adhesion + humidity control; do not fold on the outside |
| **Quill flattening** | ostrich, along a flex line | compliant bumps compress and polish | place the flex line deliberately |
| **Skive-through-relief** | ostrich, any raised surface | flat skive cuts the raised parts | skive from the flesh side; accept a thicker finished edge |
| **Edge chipping** | stingray, crocodilian | hard plates at the cut line | bind the edge; do not burnish |
| **Flesh-side peeling when glued** | fish leathers ~ | weak flesh split | line it; test glue on scrap |
| **Cannot be thinned** | elephant | deep wrinkles are structural; floor **~1.2 mm** ✓ | design at thickness; do not skive |
| **Colour loss under wear** | camel ~ | finish wear | accept patina; condition often |
| **Wrinkle ≠ crease confusion** | any finished leather | two different instabilities | `../durability.md` §2b |

## 5. Shape-constraint matrix — how the raw material constrains layout

**Area in square feet tells you almost nothing. Shape decides what you can make.**

| Material | Raw shape | Usable run | Consequence |
|---|---|---|---|
| Bovine side | large irregular half-hide | long, if cut along the backbone | the default; nest around belly and shanks |
| Bovine bend / butt | compact rectangle-ish | long and wide | prime panels |
| Equine front | ~⅔ of hide, broad | long | garment-weight panels |
| Equine strip | narrow transverse band | **short and wide** | belts, straps, sheaths |
| **Shell cordovan** | **two ovals, 1–2.5 sq ft each** | **no long run at all** | short wide parts: watch straps, card wallets, shoe quarters |
| Ostrich crown | **diamond, ⅓ of hide** | long if straight along the spine | quill must run evenly the whole length of a strap |
| Ostrich leg | **narrow strip, ~18 × 8 in** ✓ | one direction only | watch straps, accents |
| Crocodilian belly | width quoted, e.g. 47 cm on a 50/54 skin ✓ | **panel-shaped** | plan the object around the belly first |
| Crocodilian tail | long, tapering | tapering parts | graduating texture is a feature |
| Snake | **a tube**, widest at mid-body | one long run down the body | straps must run along the axis |
| Stingray | small, roughly disc/oval | **flat panels only** | inlays, cases, cuffs |
| Salmon | **~60–65 × 10–14 cm** ✓ | long and very narrow | thin strips, bookmarks, small straps |
| Eel | long thin strip with a **central ribbed band** | long | deliberately feature the rib |
| Chicken | **tiny**; a strap may need 2+ hens ~ | small patches | joinery becomes part of the design |
| Toad | **17–27 cm square-ish** ✓ | small | novelties, inlays, jewellery |
| Kangaroo | 5–7 sq ft ✓, whole-skin uniform | long | the best area-to-consistency ratio |
| Elephant | thick slab, floor ~1.2 mm ✓ | — | thickness is the constraint, not area |

## How to use this file without it becoming a shortcut you regret

1. **§1 is an index, not a specification.** It tells you which file to open.
2. **§2 is the only place species are compared directly** — and the comparisons are
   deliberately coarse, because fine comparison across species requires the same test on both,
   which almost never exists.
3. **§3 exists because the vocabulary is the main hazard.** If a supplier's word does not
   appear here with a level, ask them which level they mean.
4. **§4 is where the exotic materials earn their complexity.** Nine of the thirteen failures
   have nothing to do with bulk strength.
5. **§5 is the matrix most often skipped and most often decisive.** A shell cordovan oval
   cannot make a 300 mm strap no matter how much you paid for it.

## Known gaps in this matrix

- **Region data does not exist for most species.** Nine of the animals in §1 have a properly
  documented regional study; the rest have a general rule and nothing more. The file says
  which is which rather than inventing uniformity.
- **No cross-species mechanical test set exists.** Every strength comparison here is either
  within one study or across vendor claims with no method.
- **Grades are conventions.** Ostrich is graded by the centimetre on blemishes with
  "subjective" follicle standards ✓; crocodilian on the midsection with a 4- or 5-tier system
  ✓. Neither is portable between sellers.
