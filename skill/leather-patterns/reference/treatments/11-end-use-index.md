# Reverse index — end use → what to ask for

`08-property-matrix.md` answers **"what does this treatment do?"**. This file answers the
question a designer actually has: **"what treatment stack does this object need?"**

Read a row as a starting spec, then use the matrix to see what it costs.

---

## The stacks

Format: **anatomy → tannage → post-tan → finish**. Anatomy selections are in `../anatomy/`.

| End use | Stack | Why | The cost |
|---|---|---|---|
| **Wallet / card holder, structured** | bovine shoulder or bend → **veg or combination** → restrained fatliquor, toggle-dried → **full or semi-aniline** | holds an edge, burnishes, patinas | water-spots; will darken; stiffer to break in |
| **Wallet, soft / "vintage"** | bovine → **chrome + veg retan** → generous fatliquor, milled → **aniline or pull-up** | drape, instant softness, character | **coarse break**; edges must be painted |
| **Wallet, luxury, raw-edge** | bovine butt or **shell cordovan** → veg → firm → aniline | the leather *is* the product | expense; limited area; no edge paint needed |
| **Belt / strap** | **bovine bend or butt**, full thickness → veg, pit-tanned | takes load, holds shape, does not stretch | heavy; breaks in slowly |
| **Sole / hard-wearing** | **bend**, dense → veg, pit-tanned, heavily compressed | abrasion and water | very stiff; needs long wear-in |
| **Lining** | bovine or goat split, ~0.6–0.8 mm → chrome → drum-dyed → **no coating** | thin, smooth, colour-matched | minimal protection |
| **Bag body, structured** | bovine shoulder → combination → retan for body → semi-aniline | holds a shape | weight; corners abrade |
| **Bag body, soft / slouchy** | lamb, goat or chrome bovine → chrome → heavy fatliquor, milled → aniline | drape | **no shape retention** by design |
| **Garment / jacket** | lamb, goat, or light bovine → chrome or aldehyde → very soft, milled → aniline | drape, movement | **weak at seams**; will not hold a crisp form |
| **Glove** | hair sheep / capeskin → **aldehyde or alum-veg** → very soft → aniline | the softest leather there is | **lowest strength**; not repairable |
| **Boot upper** | bovine full grain, 1.4–1.8 mm → chrome → **water-resistant retan** → semi-aniline or full grain | water, flex, abrasion | will not patina if coated |
| **Boot lining** | sheep or bovine split → chrome → drum-dyed | soft against the foot | weak |
| **Shoe sole (leather)** | **bend**, veg, pit-tanned | the classic | stiff, slippery when wet |
| **Watch strap / small strap** | bovine or **shell**, thin → veg → firm → aniline | edge burnish, fine thickness | will water-spot |
| **Phone / device case** | bovine → chrome → firm retan → **semi-aniline or pigmented** | abrasion, stain, dimensional stability | no patina; film can crack at corners |
| **Notebook cover** | bovine → veg → firm → aniline or **nubuck** | takes impressions, patinas | nubuck stains |
| **Tool roll** | bovine **split or shoulder**, thick → veg or chrome → firm | abuse, oil contact | crude; will stain |
| **Furniture / upholstery, protected** | bovine, 1.2–1.4 mm → chrome → pigmented | stain and fade resistance | lowest breathability |
| **Furniture, pure aniline** | bovine, **top-grade hide only** → chrome → aniline | the most natural | **stains, fades, and needs a top-grade skin** |
| **Furniture, pull-up / waxed** | bovine → chrome → wax → pull-up | character, ages | marks and dries out |
| **Hair-on / shearling garment** | sheepskin → hair-saving beamhouse → chrome or combination → **pile kept** | insulation | see `09-hair-on-shearling.md` |
| **Transparent / display piece** | pelt → **index-matched fill** → direct acid dye → no finish | the effect | **weak, Ts 50–70 °C, not for hinges** |
| **Conductive / interactive** | chrome bovine → in-situ polypyrrole | conductivity | **black**, wears, lab-scale |
| **Decorative / costume** | anything, chosen for look | — | do not assume durability |

## The inverse table: "I need X, so I must accept Y"

The most useful form of this file. Find the property you need, read the price.

| I need… | Specify | And accept |
|---|---|---|
| **A crisp burnished edge** | veg-tan or firm veg-retan | water-spots, stiffness, patina |
| **Instant softness and drape** | chrome + heavy fatliquor + milling | **coarse break**, painted edges |
| **Stain and wear resistance** | pigmented finish, PU topcoat | no patina, low breathability, a film that fails |
| **Patina that improves** | full aniline on veg or veg-retan | it stains, it fades in sun, it changes |
| **Water resistance** | chrome, water-resistant retan, DWR | not waterproof at seams; DWR wears off |
| **Heat resistance** | chrome (or THPS+veg+Al) | patina lost; environmental cost |
| **Maximum area from a hide** | splitting, shaving, toggle drying | **thinner and weaker** — the skiving paradox |
| **Zero maintenance** | pigmented finish, no DWR | it will not age well, only wear |
| **A repairable, adjustable object** | veg-tan, uncoated, burnished | it needs care and it will change |
| **Something nobody sells** | see `07-avant-garde.md` | read the last column of its table |

## Three questions to ask before committing a spec

1. **Which window is this claim about?** "Soft" is window 1 and 3. "Durable" is window 2 and 4.
   "Natural" is a claim about window 4 only. A spec that says "soft, durable, natural, cheap" is
   four different windows pulling against each other.
2. **What is the wear face, and what is behind it?** The finish protects the face; nothing
   protects a cut edge, a seam, a fold or a punched hole.
3. **What is the item's expected life, and what happens at the end of it?** A 5-year object and a
   50-year object want different tannages and different finishes. Iron-mordant black is fine for
   the first and wrong for the second ✓.
